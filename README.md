# 🚗 Vehicle Rental Management System

A robust and modern web application designed to manage a multi-tenant vehicle rental marketplace. Built with **Spring Boot 3** and **Java 17**, it provides a streamlined experience for car owners (Sellers), customers (Renters), and platform administrators.

## 🌟 Key Features

### 🏢 Administrative Control
- **Unified Dashboard**: Monitor platform-wide statistics and activities.
- **Approval System**: Manage and verify seller registrations and vehicle listings.
- **Order Management**: Oversee all bookings and payment statuses across the platform.

### 🔑 Seller/Owner Features
- **Vehicle Listing**: Register and manage vehicles with detailed specifications and pricing.
- **Seller Dashboard**: Track earnings, booking requests, and vehicle availability.
- **Profile Management**: Maintain professional seller profiles and business details.

### 👤 Renter/Customer Experience
- **Vehicle Discovery**: Browse and search for vehicles by category, pricing, and availability.
- **Seamless Booking**: Interactive booking process with real-time availability checks.
- **Secure Payments**: Integrated payment workflows for booking confirmations.
- **User Dashboard**: Track active rentals, booking history, and payment status.

## 🛠️ Technology Stack

- **Backend**: Java 17, Spring Boot 3.5.x
- **Frontend**: Modern HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Security**: Spring Security Crypto for password hashing
- **Validation**: Spring Boot Validation for robust data integrity
- **Build Tool**: Maven

## 📋 Prerequisites

- **Java JDK 17** or higher
- **Maven 3.8+**
- Your preferred IDE (IntelliJ IDEA, VS Code, or Eclipse)
